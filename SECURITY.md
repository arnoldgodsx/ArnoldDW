# Güvenlik politikası

## Güvenlik açığı bildirme

Güvenlik açıklarını herkese açık GitHub Issues alanında yayımlamayın. Bir bildirim oluşturmak için GitHub deposundaki **Security → Advisories → Report a vulnerability** akışını veya [özel güvenlik bildirimi sayfasını](https://github.com/arnoldgodsx/ArnoldDW/security/advisories/new) kullanın.

Bildirimde etkilenen sürümü, açığı yeniden üretme adımlarını, beklenen ve gerçekleşen davranışı ve varsa etkisini paylaşın. Gerçek kullanıcı verileri, parolalar, oturum çerezleri veya erişim belirteçleri eklemeyin. Ekip bildirimi inceleyip yanıtlayana kadar ayrıntıları gizli tutun.
